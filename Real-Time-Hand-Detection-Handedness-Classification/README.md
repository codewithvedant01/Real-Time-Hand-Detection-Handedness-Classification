# 🖐️ Real-Time Hand Detection & Handedness Classification

![Python](https://img.shields.io)
![OpenCV](https://img.shields.io)
![MediaPipe](https://img.shields.io)

A high-performance Computer Vision pipeline that identifies **21 3D hand landmarks** and accurately classifies hands as **Left** or **Right** in real-time.

---

## 🎯 Project Overview
This project uses **Google MediaPipe** and **OpenCV** to track hand movements with sub-millisecond latency. It is a foundational tool for Human-Computer Interaction (HCI) and gesture recognition.

### 🌟 Key Features
*   **Dual Hand Tracking:** Simultaneously identifies both hands.
*   **21-Point Skeletal Mapping:** Visualizes joints and fingertips.
*   **Live Handedness:** Real-time labeling of "Left" and "Right" hands.
*   **Mirror Calibration:** Automatic horizontal flip for an intuitive user experience.
